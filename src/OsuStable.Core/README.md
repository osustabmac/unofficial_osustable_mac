# OsuStable.Core

Clean-room engine foundation providing accurate beatmap parsing, timing math, hitobject geometry, and scoring structures.

## Modules

- **Beatmaps (`/Beatmaps`)**:
  High-performance `.osu` format parser supporting timing points, sliders, spinners, hit circles, stacking calculation, and difficulty attributes.
- **Gameplay (`/Gameplay`)**:
  Hit evaluation window math (300 / 100 / 50 / Miss), combo tracking, health drain algorithms, and replay stream structures.
