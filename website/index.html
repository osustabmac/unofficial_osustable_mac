The Classic Rhythm Experience.
Engineered Natively for Apple Silicon.

For years, enjoying classic rhythm gaming on macOS required compromise: sluggish 32-bit compatibility layers, input drift, and audio desync. This project redefines that reality. Built as an independent high-performance macOS runtime under .NET 10, it bridges the iconic classic gameplay with modern Apple Silicon hardware. Powered by a custom platform architecture, native Metal/SDL3 rendering, and direct 64-bit audio, it delivers the pure, uncompromised desktop experience your Mac deserves.

Offline Mode Only • Local beatmaps & gameplay • No Bancho connection at the moment
First run: If macOS blocks opening ("App damaged"), run in Terminal:
$ xattr -cr /Applications/osu!stable.app
⚡ Architecture & Platform Highlights
🛠️ Custom UI Platform Runtime
C# / .NET 10
Ground-up macOS desktop integration providing smooth, native window management, persistent configuration, and classic theme support without legacy Windows dependencies.
🖥️ Metal & SDL3 Graphics Pipeline
SDL3 / Metal
Ultra-responsive modern rendering engine tailored for ProMotion and Retina displays. Uncapped frame rates, zero tearing, and precise sub-pixel clarity.
🔊 Direct 64-bit Audio Synchronization
libbass ARM64
Hardware-accelerated Apple Silicon sound pipeline delivering sub-millisecond audio clock accuracy and pristine sample reproduction. Zero translation jitter.
🔤 Embedded Typography Engine
Pango / Cairo
Self-contained vector font rasterization engine rendering crisp, authentic interface typography out of the box — zero external tools or setup required.
